## コマンドの置換値

本文やコマンド内の置換欄（プレースホルダー） `{{...}}` には、右上の「各種値の設定」の値が反映されます。設定を確認してからコマンドをコピーしてください。

### 環境構築担当者が決めた値を確かめる

環境構築担当者から受け取った設定JSONを、右上の「各種値の設定」の「インポート」で読み込みます。次の値がすべて設定されていることを確かめます。

### 講師が決める値を入力する

続けて、次の値を「各種値の設定」に入力します。設定JSONに環境構築担当者のプロファイルが入っていた場合も、自分のプロファイルに書き換えます。

| 表記 | 決め方 |
| --- | --- |
| `{{PROFILE}}` | 講師本人の認証方式に合わせた名前付き AWS CLI プロファイル |
| `{{ATTENDEE_ID}}` | 開催設定ファイルの受講者一覧に登録された、操作の対象の受講者の ID（例: `user01`）。講師自身の IAM ユーザー名とは別。設定項目名は `attendees` |
| `{{RELEASE}}` | 未使用の教材リリース識別子。既存公開版は上書きしない |
| `{{MANIFEST_SHA}}` | 教材のファイル一覧と照合情報をまとめた管理ファイル（manifest）を識別する SHA-256。教材一式から配布用の版を作る `release build` の出力から、64 桁の16進数（`0`〜`9`・`a`〜`f`）を転記する。受講者ツール用の値とは別 |
| `{{MATERIALS_DIR}}` | 講師がレビューした教材だけのディレクトリ |

`{{CONFIG_DIR_SH}}` と `{{MATERIALS_DIR_SH}}` はシェル引数として引用済みの値なので、外側に引用符を追加しません。認証ファイル・期限付き URL は共通フォームの対象外です。残る `<...>` は手元で置き換え、秘密はフォームや資料に保存しません。

!!! danger "教材に秘密を混ぜない"
    認証ファイル・期限付き URL・講師自身や払出し専用 IAM ユーザーのアクセスキーを教材に混ぜないでください。

受講者ごとに配布先を確認し、認証ファイル本文や URL を共有の進捗表に貼り付けません。
