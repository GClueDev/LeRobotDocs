# LeRobot 実習と AWS 連携の進め方

SO-101（ロボットアーム）を使う LeRobot 実習（接続確認、キャリブレーション、収集、編集、学習、推論）に、AWS の認証・接続・データ転送・成果回収を組み込んだ手順です。**ロボットとカメラを動かすのは手元の Jetson／Mac、GPU 学習をするのは自分用の EC2** です。

同じデータでも、手元と EC2 では置くフォルダが違います（[値と機器の対応](reference/values.md)）。新しく開いたターミナルには前の変数が引き継がれないため、そのページで設定した変数を設定し直してください。

講師の配布データで学習する場合は、収集・送信の工程を飛ばして[収集後のデータ転送](lerobot/collect.md#transfer-to-ec2)の EC2 の確認から進めます。学習を行わない基本コースは、導入・EC2 接続の後に[配布教材の確認](dataset.md)で情報表示と、データセットの可視化・閲覧ツール Rerun での確認を行い、[成果の回収確認](save.md)へ進んでください。

## 進め方

ナビゲーションの「LeRobot」も以下の順に並んでいます。導入・EC2 接続から、収集・学習・推論、成果の回収確認・片付けまで続けて進めます。AWS への転送とモデル回収は、データを受け渡す工程で行います。

| 順番 | ページ | 実行場所 |
| --- | --- | --- |
| 準備 | [PC の準備と導入](setup.md)（右上の「各種値の設定」で配布値を入力） | 手元 |
| 準備 | [EC2 への接続](connect.md)（デスクトップを開いた後、手元のロボットの接続確認へ） | 手元 → EC2 |
| 1 | [接続の確認](lerobot/check.md) | 手元の Jetson／Mac |
| 2 | [キャリブレーション](lerobot/calibration.md) | 手元の Jetson／Mac |
| 3 | [カメラの調整](lerobot/camera.md) | 手元の Jetson／Mac |
| 4 | [データセットの収集](lerobot/collect.md)（EC2 への転送・確認まで） | 手元 → S3 → EC2 |
| 5 | [データセットの編集](lerobot/edit.md) | EC2 の Ubuntu |
| 6 | [学習](lerobot/train.md)（モデルを手元へ戻すまで） | EC2 → S3 → 手元 |
| 7 | [推論の実行](lerobot/run.md) | 手元の Jetson／Mac |
| 終了 | [成果の回収確認](save.md)、[終了時の片付け](finish.md) | 手元 |
