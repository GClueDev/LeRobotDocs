## 開始条件

1. 構築担当から運用リポジトリ `ai-learning-handson-aws-infra`、その dev container の開き方、開催設定、受講者 ID の一覧を受け取ります。AWS アカウントの管理者から、講師用の AWS のユーザー（IAM Identity Center のユーザー、または IAM ユーザー）を付与してもらいます。AWS CLI のプロファイルは、受け取るものではなく、このユーザーで自分の作業環境に作ります。
2. 運用リポジトリは構築担当が確認した版を使います。構築担当に採用版と必要な修正の包含を確認してもらいます。[出典と版の確認](<<= guide_link('verification.md#source-version') =>>) に検証時の版と修正をまとめています。
3. dev container 内の運用リポジトリ直下で `uv sync` を済ませ、`uv run gclue-ai-handson --help` で `release`、`credentials`、`rollout` が出ることを確認します。運用環境には AWS CLI v2 と Session Manager プラグイン（SSM 経由のシェル接続・ポート転送用）が必要です。
4. 開催設定の `aws.profile` を自分のプロファイル名に合わせます。認証方式に応じたログイン・キーの対話入力は本人が行います。構築担当から、対象 EC2 が起動済み・SSM 経由でシェル接続可能・受講者との対応が正しいことを確認します。

本資料はコマンド実行に必要な運用リポジトリを同梱しません。未取得なら構築担当から組織内の取得先を受け取ってください。LeRobotDocs 内で運用 CLI を実行しても環境は作成されません。
