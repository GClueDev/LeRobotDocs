## 修正版と LeRobot の注意点

講師が動作確認した配布版のツールへ更新してから、実際の対象機器で確認します。macOS で起きた `unbound variable` の修正と検証時の配布状況は[出典と版の確認](<<= guide_link('verification.md#source-version') =>>)にまとめています。

```bash
gclue-ai-handson-attendee env update
```

Git LFS は大きなデータファイル本体を Git の履歴と別に管理します。Parquet のエラーでは、未取得の本体を指す参照情報だけが残っていないか構築担当と確認し、[データ本体の取得と確認](<<= guide_link('reference/data.md#git-lfs') =>>)へ進みます。

!!! warning "LeRobot の確認範囲"
    記録では、データ本体取得後の aloha と別の1カメラ構成の Rerun 表示、編集 CLI の情報表示が成功しています。データ変更を伴う編集、GPU 学習、ResNet18 の重みの事前取得は未検証です。[講師の検証記録](<<= guide_link('staff/instructor/verification.md') =>>)を確認し、GPU 学習まで成功したと案内しないでください。
