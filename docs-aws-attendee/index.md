# AWS 講習会・{% if audience == "staff" %}講習会側{% else %}受講者{% endif %}ガイド

LeRobot AWS 講習会・{% if audience == "staff" %}講習会側{% else %}受講者{% endif %}ガイドへようこそ。

講師からは、次のものを受け取ります（詳しくは [PC の準備・導入](setup.md)の「用意するもの」）。

- 各種値の設定JSON（配られた場合）
- 受講者ごとの認証情報ファイル（`<受講者 ID>.env`。自分として AWS に接続するための一時的な認証情報）
- 導入スクリプトの期限付き URL

最初に右上の「各種値の設定」ボタンを開き、受け取った設定JSONをインポートするか、指定された値を入力してください。
認証情報ファイルと期限付き URL は本人だけが使う値なので、フォームには保存せず、使うコマンドの中の、自分で置き換える箇所に指定します。

自分で置き換える箇所は、`<…>` の形のプレースホルダー（置き換え用の目印）で書かれ、画面では 📝 の印が付きます（例：`<認証情報ファイルの絶対パス>`）。

手元の PC から自分用のクラウドサーバ（EC2 インスタンス）に接続し、LeRobot のデータセットを確認して、成果を手元に持ち帰るための手順です。AWS 資源の構築・削除は講師に任せ、受講者は配布された一時認証情報を使います。

## LeRobot 実習と AWS を組み合わせて進める

LeRobot 実習は、手元の SO-101（ロボットアーム）とカメラを使い、接続の確認、キャリブレーション、データセットの収集・編集、学習、推論までを手元の機器で行う実習です。この講習会では、そのうち学習をクラウドサーバ（EC2 インスタンス）の GPU で行います。

[LeRobot 実習と AWS 連携の進め方](aws-workflow.md)では、手元の SO-101 で収集し、S3 経由で EC2 へ送り、学習したモデルを回収して手元で推論する流れを確認できます。配布データを使う場合の途中参加や、学習を行わない基本コースの進め方も記載しています。

コマンドの別の使い方、更新、接続方法の変更、エラーへの対応は[目的から探す参照ページ](reference/index.md)にまとめています。必要なときだけ参照し、各項目のリンクから、読んでいた手順のページへ戻れます。

## 実行場所と置換値

**手元** は Mac 等のターミナル、**EC2** は SSH 接続後や DCV デスクトップ内のターミナルです。ターミナルの場所を確認してから実行します。右上の「各種値の設定」に入力した値がコード例へ反映されます。入力例やJSONの受け渡しは[設定の使い方](common.md)を参照してください。残る `<…>` は手動で置き換える箇所です。認証ファイルは絶対パスを指定し、例の引用符は残してください。

| 表記 | 講師から受け取る値 |
| --- | --- |
| `{{EVENT_ID}}` / `{{ATTENDEE_ID}}` | 自分の開催と利用者の識別子 |
| `<認証情報ファイル>` | 配布された `.env` のパス。`.credentials` も同時に配布された形式の場合だけ、2つを同じフォルダに置く |
| `<導入スクリプトの URL>` | 講師が配布する有効期限付き URL。資料には保存しない |
| `{{BUCKET}}` / `{{REGION}}` | S3 のバケット名と AWS リージョン |
| `{{DATASET_DIR}}` / `{{DATASET_REPO_ID}}` | EC2 上のデータセットの絶対パスと識別名 |

!!! danger "認証情報を人に見せない"
    認証情報・鍵・期限付き URL を Git、画面共有のログ、チャットへ貼り付けないでください。
