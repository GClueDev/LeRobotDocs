# 成果の回収を確認する

実習を終える前に、必要な成果が手元に戻り、内容も一致することを確認します。EC2の停止や認証情報の失効は、この確認が終わってから講師が行います。

## 1. コースに応じて成果を確認する

- **自分で収集・学習した場合**：[モデル回収](aws-model-recovery.md)で全チェックポイントの照合がすべて `OK` になり、手元の保存先を控えたことを確認します。推論にはその回収済みモデルを使います。
- **配布教材の内容・映像を確認した場合**：この基本コースでは学習結果を作成しません。残すメモやファイルがある場合だけ[ファイル保存の補足](reference/files.md#upload)を使います。

必要なファイルを手元で開けることを確認します。転送コマンドの成功だけで回収完了とせず、ハッシュや内容も照合します。不足・不一致があれば片付けへ進まず講師へ相談してください。

## 2. 講師へ回収結果を伝える

手元の保存先と確認結果を講師へ伝えます。全員分の確認が終わったら[終了時の片付け](finish.md)へ進みます。

保存経路を調べる場合は[小さなファイルでの疎通確認](reference/files.md#check-route)を使います。小ファイルの保存・再取得と内容一致は実測済みですが、終了時の全成果回収は今回の実測対象外です。
