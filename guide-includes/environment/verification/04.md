## 同梱スクリプトの契約 {#script-verification}

[setup-lerobot-ec2.sh](<<= guide_link('staff/environment/scripts/setup-lerobot-ec2.sh') =>>) は上記 `ccfd1a3` の実ファイルを基に掲載しています。`--cache-resnet18` の用途が伝わるようヘルプの説明文を更新し、実行処理は維持しています。Ubuntu 24.04 x86_64 の `ubuntu` ユーザー向けで、sudo とインターネット接続が必要です。OS パッケージ、uv、AWS CLI、LeRobot の固定版を導入します。既存版や Git SHA、追跡ファイルの変更が合わない場合は停止します。

NVIDIA ドライバー、SSM Agent（EC2 側で接続・操作を受け付けるソフトウェア）、SSH、Amazon DCV（リモートデスクトップ接続）の導入、AWS リソース作成、認証情報の払出し、データセット取得、学習は行いません。元の検証では構文、ヘルプ、隔離 mock 14 ケースが成功していますが、**スクリプト全体の EC2 実行は未検証**です。手動で同じ依存が導入できたことは、一括実行成功の証明ではありません。LeRobotDocs 側では構文とヘルプ、ヘルプを除く実行処理が元ファイルと一致することを確認します。

インスタンスストア NVMe の利用は将来の検討項目です。この手順で自動フォーマットは行いません。
