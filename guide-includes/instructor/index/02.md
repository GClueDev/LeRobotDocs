## コマンドの置換値

最初に右上の「各種値の設定」ボタンを開き、開催 ID・受講者 ID・リージョン・プロファイル・開催設定ディレクトリ・教材の版などを入力します。本文やコマンド内の置換欄（プレースホルダー） `{{...}}` には、その設定の値が反映されます。設定を確認してからコマンドをコピーしてください。

`{{CONFIG_DIR_SH}}` と `{{MATERIALS_DIR_SH}}` はシェル引数として引用済みの値なので、外側に引用符を追加しません。認証ファイル・期限付き URL は共通フォームの対象外です。残る `<...>` は手元で置き換え、秘密はフォームや資料に保存しません。

| 表記 | 決め方 |
| --- | --- |
| `{{CONFIG_DIR}}` | 構築担当が配った開催設定ディレクトリのパス |
| `{{EVENT_ID}}` | 開催設定ファイルの開催 ID。[導入済み環境の設定を確認する受講者用コマンド](<<= guide_link('setup.md#3') =>>) `gclue-ai-handson-attendee env info` に表示される開催 ID と一致させる |
| `{{ATTENDEE_ID}}` | 開催設定ファイルの受講者一覧に登録された本人の ID（例: `user01`）。講師自身の IAM ユーザー名とは別。設定項目名は `attendees` |
| `{{PROFILE}}` | 講師本人の認証方式に合わせた名前付き AWS CLI プロファイル |
| `{{RELEASE}}` | 未使用の教材リリース識別子。既存公開版は上書きしない |
| `{{MANIFEST_SHA}}` | 教材のファイル一覧と照合情報をまとめた管理ファイル（manifest）を識別する SHA-256。教材一式から配布用の版を作る `release build` の出力から、64 桁の16進数（`0`〜`9`・`a`〜`f`）を転記する。受講者ツール用の値とは別 |
| `{{MATERIALS_DIR}}` | 講師がレビューした教材だけのディレクトリ |
| `{{BUCKET}}`・`{{REGION}}` | 開催設定と構築担当から取得。資料に実値を保存しない |

認証ファイル・期限付き URL・講師の鍵を教材に混ぜないでください。受講者ごとに配布先を確認し、認証ファイル本文や URL を共有の進捗表に貼り付けません。
