## 6. 講習会の終了後

!!! warning "終了フローは未検証です"
    以下は一次資料と CLI 実装の照合に基づく手順です。最終成果回収、認証情報の失効、バックアップ削除、環境撤去は実 AWS での通し実行を確認していません。[講師の検証記録](<<= guide_link('staff/instructor/verification.md') =>>)と[終了チェック](<<= guide_link('staff/instructor/closing.md') =>>)を確認し、全員の再取得・内容一致を確認してから片付けます。

1. 受講者に、残したい成果を自分の保存場所へアップロードしてもらう（`gclue-ai-handson-attendee files upload`、[受講者の手順](<<= guide_link('staff/instructor/support.md') =>>)）。
2. 一斉配布で作ったバックアップ（スナップショット）を削除する。

   ```bash
   uv run gclue-ai-handson rollout cleanup-snapshots \
     --env-dir {{CONFIG_DIR_SH}}
   ```

   削除するスナップショットの一覧が表示され、確認を求められたら `y` を入力します。
   `<件数> 件を削除しました` または `削除するスナップショットはありません` と表示されれば終わりです。
   `--patch-id <パッチ ID>` や `--attendee {{ATTENDEE_ID}}` で対象を絞れます。
3. 全員の認証情報を取り消す（[全員の認証情報を取り消す](<<= guide_link('staff/instructor/operations.md#52') =>>)）。
4. 構築担当に、講習会が終わったことを伝える。

   環境の撤去は構築担当が行います（[講習会用 AWS 環境の構築と撤去](<<= guide_link('staff/environment/procedures/environment.md') =>>)）。
