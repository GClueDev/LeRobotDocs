# 調べたいとき：目的から探す

通常の実習は[実習の進め方](../aws-workflow.md)または[基本コースの流れ](../index.md)の順に進めます。ここは、設定を変えたいときや、うまくいかないときに必要な項目だけを調べるためのページです。受講者ツールのコマンド名を覚えておく必要はありません。

| 調べたいこと | 参照先 |
| --- | --- |
| 必要なソフトを入れる・Windowsで使う・導入先を変える | [導入の詳しい説明](setup.md) |
| 認証情報の期限切れ・ツールや教材の更新 | [更新と認証情報](setup.md) |
| SSH・VS Code・GitでEC2へ接続する・DCVのポートを変える | [接続方法の詳しい説明](connect.md) |
| 配布データを別途取得する・教材を再取得する | [ファイルの取得](files.md) |
| Git LFS・Parquet・データ表示の問題を調べる | [データ確認と復旧](data.md) |
| 通し実習と別の成果をS3へ保存・取得する・小さなファイルで経路を試す | [ファイルの保存と取得](files.md) |
| 設定名の意味やコマンドの値の選び方を調べる | [設定値の詳しい説明](values.md) |
| エラーの症状から原因と対応を探す | [困ったとき](../troubleshooting.md) |

値を入力する場所は、全ページ右上の「各種値の設定」ボタンです。入力例や保存の仕組みは[設定の使い方](../common.md)で説明しています。認証情報や期限付きURLは保存しません。講師の設定JSONを受け取った場合はインポートし、残った項目だけを本人の機器に合わせて設定してください。
