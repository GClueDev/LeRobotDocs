## 4. 構築する

`--approve` を付けて実行します（付けないと実行されません）。

```bash
uv run gclue-ai-handson-cdk --env-dir {{CONFIG_DIR_SH}} deploy \
  --approve
```

完了するまで画面には何も表示されません（10〜20 分）。
途中の様子は、AWS マネジメントコンソールの CloudFormation の画面で、スタック `GClueAiHandsOn-{{EVENT_ID}}` のイベントから確かめられます。

成功したことを確かめます。
`CREATE_COMPLETE`（2 回目以降の構築では `UPDATE_COMPLETE`）と表示されれば成功です。

```bash
aws --profile {{PROFILE_SH}} --region {{REGION}} \
  cloudformation describe-stacks \
  --stack-name GClueAiHandsOn-{{EVENT_ID}} \
  --query 'Stacks[0].StackStatus' --output text
```

受講者ごとの EC2 が動いていることを確かめます。
受講者 ID ごとに 1 行ずつ、`running` と表示されます。

```bash
QUERY='Reservations[].Instances[].[Tags[?Key==`attendee`]|[0].Value,'
QUERY+='InstanceId,State.Name]'

aws --profile {{PROFILE_SH}} --region {{REGION}} \
  ec2 describe-instances \
  --filters Name=tag:handson-deployment,Values={{EVENT_ID}} \
  Name=instance-state-name,Values=pending,running --query "$QUERY" \
  --output text
```

失敗した場合は「うまくいかないとき」を参照してください。

確認で表示された受講者 EC2 の InstanceId を、接続確認をする場合だけ入力します。例: `i-0123456789abcdef0`。AMI 作成用の一時 EC2 ID の欄とは別です。
