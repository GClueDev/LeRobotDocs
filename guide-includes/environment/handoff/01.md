## 引き渡しの成功条件

- [払出し用の鍵ができたことを確かめる](<<= guide_link('staff/preparation/verify.md#51') =>>)の暗号化パラメータが存在し、[講師に払出し用のアクセスキーを読む権限を与える](<<= guide_link('staff/preparation/verify.md#52') =>>)の権限を持つ講師がツールを実行できる。
- SSM 経由でシェル接続でき、Linux ユーザー `ubuntu` への切替（sudo）、SSH ホスト鍵、`git`、`flock` が確認できる。
- Amazon DCV（リモートデスクトップ接続）を使う場合、ログインと GUI が動く。灰色画面は通常のログアウト／ログインで回復した実測がある。Ubuntu のデスクトップ環境 GNOME の重要なプロセスを強制終了しない。改善しなければ講師へ相談する。
- LeRobot の版・依存と、Git LFS で実データが取得されていることを確認する。
- 受講者ツールは macOS Bash 3.2 / C.UTF-8 の日本語隣接変数修正 `fc6e58d` を含む版を講師が公開・配布する。修正版の Git 往復は確認済みだが、配布済み旧版の更新は未完了（修正版はローカル build / dry-run のみで、公開されていない）。
