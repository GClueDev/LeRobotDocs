## 作業場所と用意する版

この LeRobotDocs は教材です。構築コマンドは別の運用リポジトリ `ai-learning-handson-aws-infra` が提供します。このリポジトリを手元に `git clone` して使います。

以下を手元の ターミナル で実行します。

```bash
git clone git@github.com:GClueDev/ai-learning-handson-aws-infra.git
cd ai-learning-handson-aws-infra
git rev-parse --short HEAD
git status --short
```

表示された版を記録し、作業中の変更がないことを確認します。ドキュメントを置いた LeRobotDocs では `uv run gclue-ai-handson-cdk` は実行できません。

| 場所 | 実施すること |
| --- | --- |
| 手元・インフラリポジトリ直下 | 設定ファイル、CDK、AWS CLI、講師向け運用 CLI |
| 手元・LeRobotDocs 直下 | 同梱スクリプトの転送、教材ビルド |
| EC2・`ubuntu` ユーザー | LeRobot 導入、依存確認、データセット表示 |
| AWS 管理者／講師 | 権限設定、認証情報払出し、教材配布 |

[共通設定](<<= guide_link('common.md') =>>) でプロファイル、リージョン、アカウント ID、開催 ID、設定ディレクトリ、AMI ID、インスタンス ID などを入力します。`<SSH 接続先>` などフォーム対象外の値は各工程で個別に確認します。設定や認証情報を教材に書き戻さず、担当者間の非公開経路で共有してください。
