## 8. 使わなくなった導入済みの AMI を削除する {#8-使わなくなった導入済みの-ami-を削除する}

[（任意）ソフトウェアを導入済みの AMI を用意する](<<= guide_link('staff/preparation/ami-find.md#24-ami') =>>) で作った導入済みの AMI は、複数の開催で使い回すため、講習会ごとの撤去（[撤去する](<<= guide_link('staff/environment/procedures/environment.md#7-撤去する') =>>)）では削除しません。
どの開催でも使わなくなった AMI は、開催の流れとは別に、構築担当が次の順で削除します。
AMI とそのスナップショットは、保存している間ずっと料金がかかります。

必要な権限は [アクセス制御の仕様](<<= guide_link('staff/environment/specs/access-control.md') =>>) の「管理者の作業」にあります（`AdministratorAccess` があれば足ります）。

### 8.1 削除する AMI を選ぶ

導入済みの AMI の ID、名前、作成日時、説明を表示し、削除する AMI の ID を選びます。このページの `<削除する AMI ID>` を、その確認済み ID（例: `ami-0123456789abcdef0`）へ手動で置き換えます。開催の起動に使う AMI ID の設定欄とは別の削除対象です。引用符は残し、未置換のまま実行しません。

```bash
aws --profile {{PROFILE_SH}} --region {{REGION}} \
  ec2 describe-images --owners self \
  --filters Name=tag-key,Values=gclue-ai-handson-ami \
  --query 'Images[].[ImageId,Name,CreationDate,Description]' \
  --output text
```

### 8.2 使われていないことを確かめる

1. 手元の開催の設定ファイルに、その AMI ID が書かれていないことを確かめます。

   リポジトリ直下で実行し、何も表示されなければ書かれていません。
   先に `git pull` で、ほかの構築担当がプッシュした設定ファイルも取得しておきます。

   ```bash
   git pull
   grep -r "<削除する AMI ID>" config/environments/
   ```

2. その AMI から起動したインスタンスが残っていないことを確かめます。

   何も表示されなければ残っていません。
   表示された場合は、そのインスタンスの開催が撤去されるまで削除しません。
   削除すると、その開催で EC2 を作り直すときに起動できなくなります。

   ```bash
   QUERY='Reservations[].Instances[].[InstanceId,State.Name,'
   QUERY+='Tags[?Key==`handson-deployment`]|[0].Value]'

   STATES='Name=instance-state-name,Values=pending,running,stopping,'
   STATES+='stopped'

   aws --profile {{PROFILE_SH}} --region {{REGION}} \
     ec2 describe-instances \
     --filters Name=image-id,Values='<削除する AMI ID>' \
     "$STATES" \
     --query "$QUERY" --output text
   ```

### 8.3 AMI とスナップショットを削除する

1. AMI のスナップショット ID を表示し、控えておきます（`snap-` で始まる値）。

   ```bash
   aws --profile {{PROFILE_SH}} --region {{REGION}} \
     ec2 describe-images --image-ids '<削除する AMI ID>' \
     --query 'Images[0].BlockDeviceMappings[].Ebs.SnapshotId' \
     --output text
   ```

2. AMI の登録を解除します。

   この操作は元に戻せません。

   ```bash
   aws --profile {{PROFILE_SH}} --region {{REGION}} \
     ec2 deregister-image --image-id '<削除する AMI ID>'
   ```

3. AMI のスナップショット確認結果で控えた ID（例: `snap-0123456789abcdef0`）を `<スナップショット ID>` へ手動で転記し、ID ごとに、スナップショットを削除します。

   AMI の登録の解除より先に実行すると、使用中のためエラーになります。

   ```bash
   aws --profile {{PROFILE_SH}} --region {{REGION}} \
     ec2 delete-snapshot --snapshot-id '<スナップショット ID>'
   ```

4. [削除する AMI を選ぶ](<<= guide_link('staff/environment/procedures/environment.md#81-ami') =>>) のコマンドをもう一度実行し、削除した AMI が表示されなくなったことを確かめます。
